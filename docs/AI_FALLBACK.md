# Housing help without AI

The Cloudflare Pages home screen links to **Find Housing Help Without AI** and **I Need Housing Help**. The directory and optional nine-situation guide are compiled into static Pages assets, so browsing, triage and plan generation do not call Workers AI, embedding services, vector search, the chat API, D1 or the backend Worker. Users can view emergency resources immediately, skip intake questions, and copy, print or save a plan without an account. The frontend does not send guide selections to a server. A downloaded plan or clipboard copy may be visible on a shared device.

The directory covers eviction help, homelessness assistance, legal assistance and emergencies. Each entry gives an organization and program name, a short description, geographic coverage, an official website and source URL, a publicly listed contact, eligibility when the publisher states it, and a last verification date. An unverified live opening, intake slot, funding balance or application status must never be presented as available. The date describes when the listed source was checked, not a promise that a program is accepting applications today. Follow the official link or contact the listed organization to confirm current details.

Chat remains available when it can answer. Workers AI adds conversational explanations and quote-only cited answers from the reviewed RAG corpus. If inference fails, the backend can provide its deterministic extractive answer when evidence exists. If chat itself is unavailable, the Pages directory still loads as a static asset. The UI says: **“TampaBayBot's AI chat is temporarily unavailable. You can still browse verified housing assistance resources.”** It never displays provider stack traces or raw error bodies. A known application limit can show its 00:00 UTC reset; a Cloudflare outage or provider quota error should not promise a recovery time.

The directory is a navigation aid. It does not decide eligibility, give legal advice, reserve shelter space or submit an application. In immediate danger, call 911; for local information and referrals, use the official contacts listed in the directory. Users should confirm details with the responsible organization before relying on a program or court procedure.

## Independence check

For a release, build the Pages assets and serve them while the backend and Workers AI are deliberately disabled. From the homepage, open **I Need Housing Help**, find at least one official eviction, homelessness, legal-aid and emergency resource, filter by each supported county, and open or copy an official contact. The directory must make no inference request. The automated Pages tests cover this path. On October 9, 2026, the hosted Pages preview passed desktop and mobile checks of all four categories, official links, and zero API calls while filtering; the backend model was also disabled. Recheck the hosted site after each deployment.

The directory itself is only as current as its last source review. Plans prefer recently source-checked contacts. When none match, a plan may show an older contact as **Needs recheck**, with its check date and an instruction to confirm the official source directly. Closed, unavailable-source and geographically inapplicable records are excluded from plans. The directory remains browsable with per-record warnings. Update the structured records after checking official publisher pages, record a new verification date, and rebuild Pages. The [resource provenance notes](../pages-demo/src/HOUSING_RESOURCES.md) describe the current page checks and their limits. The chat corpus and directory have separate review cycles. A backend outage does not automatically update a static listing.
