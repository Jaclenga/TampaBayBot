# Cloudflare AI cost controls

Checked against Cloudflare's documentation on October 9, 2026. The prepared deployment remains on **Workers Free** and does not enable paid inference. [Workers AI pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/) lists 10,000 free neurons per account per day and says calls beyond that allowance fail on Free. The account allocation is shared with other Workers AI uses. Cloudflare documents [error 3036](https://developers.cloudflare.com/workers-ai/platform/errors/) for exhausted free neurons. The application recognizes this separately from timeouts, unavailable models and other provider failures, and stops repeated inference attempts after a quota error. The static directory remains accessible.

## What the caps cover

The D1 backed controls reserve at most **15 model attempts per visitor per UTC day** and **100 model attempts across the deployment per UTC day** by default. They also cap simultaneous model attempts (`TAMPABAYBOT_LIMIT_MODEL_CONCURRENCY`), prompt bytes (`LLM_MAX_PROMPT_BYTES`) and generated output tokens (`LLM_MAX_OUTPUT_TOKENS`). The backend counts a reserved attempt even when generation fails, and records successful, failed and rejected attempts separately. An application cap prevents ordinary public traffic from continuing to invoke inference after that cap is reached. It is **not a neuron meter or guaranteed financial ceiling**.

For the default [`@cf/meta/llama-3.1-8b-instruct-fp8`](https://developers.cloudflare.com/workers-ai/models/llama-3.1-8b-instruct-fp8/) model, Cloudflare currently lists 13,778 neurons per million input tokens and 26,128 per million output tokens. A hypothetical 2,500-input-token and 400-output-token call uses about 44.9 neurons; 100 such calls use about 4,490. Actual prompts, generated lengths, other account activity, model overrides and pricing can differ. Exact provider consumption is not known before `AI.run`, and a failed call may not return usable usage data. The app therefore does not convert its request counter into a purported exact neuron or dollar balance. Check the Cloudflare Workers AI dashboard for provider-side usage.

The Free plan refuses exhausted Workers AI calls. It does not turn them into paid overages. If an operator later enables Workers Paid, this application's request limit alone cannot guarantee a maximum bill; operator review of model choice, provider neuron metrics and paid-plan controls is required. Do not enable a paid plan as part of routine fallback or quota recovery. The separate [cost estimate](../COST_ESTIMATE.md) includes sample token mixes and Cloudflare service limits.

## Other resource limits

- [Pages static assets](https://developers.cloudflare.com/pages/functions/pricing/) are served without Function invocations when `_routes.json` includes only `/api/*`; that is why the housing directory is in the Pages bundle.
- The API uses Workers requests and D1 queries. [Workers Free limits](https://developers.cloudflare.com/workers/platform/limits/) include 100,000 requests per day and a 10 ms CPU time limit per request. [D1 Free pricing](https://developers.cloudflare.com/d1/platform/pricing/) includes 5 million rows read and 100,000 rows written per day, plus 5 GB storage. Other account traffic shares relevant quotas. Quota failure in the API must not block static assistance pages.
- The default model timeout and output-token limit bound slow or unusually long inference, and the operations layer limits requests, outbound calls and concurrency. These safeguards protect normal usage but do not cover every platform cost or a distributed bot attack. Use Cloudflare's dashboard and deployment protections for account-wide traffic.

Configure values in the backend Worker runtime, not in the Vite frontend. See [AI usage limits](AI_USAGE_LIMITS.md) for the variable names and accounting rules, and [Cloudflare deployment](../CLOUDFLARE_DEPLOYMENT.md) for the prepared free-plan configuration. A change to `LLM_MODEL` requires checking the new model's token window, output bounds, pricing and error behavior, then rerunning model and hosted smoke tests.
