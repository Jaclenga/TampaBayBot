# Cloudflare demo cost estimate

Checked against Cloudflare's published prices and limits on October 9, 2026. This is a capacity estimate for the proposed Pages frontend, Pages Function proxy, vinext backend Worker, Workers AI, and D1 operations database. It is not a usage measurement or a guarantee of successful hosted inference. Keep the account on **Workers Free**; do not enable Workers Paid, prepaid AI Gateway credits, or another paid service for this demo.

## Inference is the tightest free limit

Cloudflare currently lists [`@cf/meta/llama-3.1-8b-instruct-fp8`](https://developers.cloudflare.com/workers-ai/models/llama-3.1-8b-instruct-fp8/) as a hosted model with a 32,000-token context window. Its [published price and neuron rates](https://developers.cloudflare.com/workers-ai/platform/pricing/) are $0.152 and 13,778 neurons per million input tokens, plus $0.287 and 26,128 neurons per million output tokens. Workers AI grants **10,000 neurons per account per day** on Free, shared with any other AI use in that account. The allocation resets at 00:00 UTC. Free usage beyond it fails rather than turning into an overage charge; Cloudflare documents [HTTP 429, error 3036](https://developers.cloudflare.com/workers-ai/platform/errors/) for exhaustion.

For planning, assume one model call per eligible cited question, with **2,500 input tokens** for the instructions, bounded question, retrieved government passages and output schema, and **400 output tokens** for the quoted-answer JSON. That is plausible for this retrieval workflow but has not been measured against a deployed corpus. One call uses about `2,500 × 13,778 / 1,000,000 + 400 × 26,128 / 1,000,000 = 44.8962` neurons. Monthly rows use 30 days at the same daily volume.

| ---: | ---: | ---: | ---: | ---: | --- |
| 100 | 250,000 / 40,000 | 4,490 | 3,000 / 7.5M / 1.2M | $1.48 | Within the AI allocation if other account use is low. Actual inference charge: $0. |
| 500 | 1.25M / 200,000 | 22,448 | 15,000 / 37.5M / 6M | $7.42 | Exceeds the daily AI allocation. |
| 1,000 | 2.5M / 400,000 | 44,896 | 30,000 / 75M / 12M | $14.84 | Exceeds the daily AI allocation. |

The dollar column prices all hypothetical calls at published model rates; it is **not** a Free-plan bill. With this token mix and no other account AI use, `floor(10,000 / 44.8962) = 222` calls fit before Cloudflare's daily AI limit. The backend also defaults to **15 eligible model attempts per visitor** and **100 model attempts across all visitors per UTC day**, reserved atomically through D1, with two simultaneous calls. It falls back to its extractive answer if model generation cannot run or fails validation. Thus 500 or 1,000 daily questions do not imply 500 or 1,000 model calls in the configured demo. A model attempt can still consume neurons when its returned answer later fails application validation. Questions with no supported evidence do not need a model call. The separate default of **1,000 resident API requests per UTC day** includes chat and location, property, and development lookups; 1,000 questions plus any of those extra lookups will hit the application limit. See [AI usage limits](docs/AI_USAGE_LIMITS.md) for accounting and [cost controls](docs/CLOUDFLARE_COST_CONTROLS.md) for financial limits.

The implementation bounds the model request with `LLM_MAX_PROMPT_BYTES` (default and maximum 12,000 serialized UTF-8 bytes) and generated output with `LLM_MAX_OUTPUT_TOKENS` (default 512; allowed 128–512). Bytes are not tokens; the 100-call application cap does **not** prove that 10,000 neurons will last all day. Longer retrieved passages, larger outputs, other Workers AI activity, retries and model price changes reduce available capacity. Keep the Workers AI dashboard in view and expect honest model fallback when limits are reached. On Workers Free there is no AI overage charge to surprise the operator. Raising the application model cap does not raise Cloudflare's Free allocation.

## Other Cloudflare limits

- [Pages static assets](https://developers.cloudflare.com/pages/functions/pricing/) are free and unlimited when they do not invoke a Function. The demo's `_routes.json` includes only `/api/*` so ordinary HTML/CSS/JS and the non-AI housing directory remain static even when inference fails. API calls share the [Workers Free limit of 100,000 requests per day](https://developers.cloudflare.com/workers/platform/limits/) across the account. A Pages Function forwards allowed API requests to the backend through a service binding. At 100–1,000 questions/day, application traffic is below the published request limit, but other account traffic and extra location, property or development requests count too. Free Workers also have 10 ms CPU per invocation, 128 MB memory, 50 subrequests per request and a 3 MB Worker size limit. The larger vinext backend and reviewed corpus must be verified against these hosted limits. Local Node timing is only a screening measurement, not a Cloudflare CPU measurement.
- [D1 Free](https://developers.cloudflare.com/d1/platform/pricing/) includes 5 million rows read/day, 100,000 rows written/day and 5 GB total storage. It stores shared request, concurrency, outbound and model-call counters plus aggregate metrics. These are operation quotas, not a fixed number of questions: actual D1 rows used per question depend on the path, cleanup and retries. Monitor row metrics after deployment. The database contains no resident question text or raw IP address.
- [Pages Free](https://developers.cloudflare.com/pages/platform/limits/) permits 500 builds/month, 20,000 site files and 25 MiB per static asset. Git pushes to the linked production and preview branches can trigger builds, so configure branch controls to avoid unnecessary preview builds.
- The [Workers AI text-generation rate limit](https://developers.cloudflare.com/workers-ai/platform/limits/) is currently 300 requests/minute for models that do not require Workers Paid. It is an account throughput ceiling, not a daily cost guard. The backend's lower D1 limits govern demo traffic.

The existing frontend and backend have no paid vector database. Retrieved source content is compiled into the reviewed Worker artifact; public GIS requests use existing external civic services and may have their own availability or use limits. This estimate excludes any non-Cloudflare costs the operator independently enables.

## Monitor before changing limits

Use the Cloudflare Workers AI dashboard for actual neurons, Workers & Pages metrics for Function/Worker requests and errors, and D1 **Metrics → Row Metrics** for reads, writes and storage. The protected `/api/operations` endpoint reports aggregate application limits and recent requests; see [production operation](docs/OPERATIONS.md). Keep `TAMPABAYBOT_LIMIT_MODEL_PER_DAY=100` or lower until a reviewed corpus and real usage measurements justify a change. Cloudflare [Workers Paid starts at $5/month](https://developers.cloudflare.com/workers/platform/pricing/) and bills AI neurons above the daily free allocation; enabling it is outside this $0 deployment plan.
